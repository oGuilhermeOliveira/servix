# 🐝 Servix

O **Servix** é uma plataforma que conecta clientes a profissionais autônomos especializados em serviços residenciais, facilitando a busca por profissionais para atividades como elétrica, encanamento, pintura, limpeza e instalações.

O objetivo do projeto é simplificar a contratação de serviços, aproximando clientes e prestadores de forma prática e acessível, além de oferecer maior visibilidade aos profissionais e novas oportunidades de trabalho.

Desenvolvido com tecnologias web, o Servix busca oferecer uma experiência intuitiva, centralizando diferentes categorias de serviços em uma única plataforma, com foco inicial na região do Alto Tietê, em São Paulo.

🌐 **Acesse o projeto:** https://servix-rosy.vercel.app/
